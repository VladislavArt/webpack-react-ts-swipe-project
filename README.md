# 🕰 Исторические даты (Interactive Timeline)

Интерактивный виджет для визуализации хронологии событий. Проект построен на сложной математической модели вращения и кастомной сборке.

## 🚀 Ключевые особенности

*   **Математическая модель анимации (GSAP):**
    *   Реализовал позиционирование элементов по окружности с использованием тригонометрических вычислений.
    *   **Counter-rotation:** настроил компенсационное вращение точек при повороте основного круга, чтобы контент внутри них всегда сохранял горизонтальную ориентацию.
    *   Анимация смены чисел реализована через GSAP Timeline с синхронизацией стейта в колбэках.
*   **Интеграция Swiper:** Реализовал внешнее управление слайдером через `useRef`. Настроил логику автоматического сброса позиции слайдера при смене временного периода.
*   **Типизация:** TypeScript, использование Literal Types для строгой валидации ключей дат и контента.

## ⚙️ Сборка (Webpack 5)

Конфигурацию сборки выполнил полностью с нуля, чтобы гибко настроить процесс под конкретные задачи проекта.

*   **Декомпозиция конфигурации:** Логику разделил на модули (лоадеры, плагины, резолверы) для масштабируемости.
*   **Multi-platform Build:** Реализовал условную сборку через `Environment Variables` для генерации специфичных бандлов под Desktop и Mobile.
*   **Оптимизация и DX:**
    *   Интегрировал `React Refresh` для HMR без потери состояния компонентов.
    *   Внедрил `ForkTsChecker` для выноса проверки типов в отдельный поток (ускорение сборки).
    *   Настроил `SVGR` для импорта SVG в виде React-компонентов.
    *   Интегрировал `Bundle Analyzer` для мониторинга веса итоговых чанков.

## 🛠 Стек технологий

- **Core:** React 19, TypeScript, Webpack 5
- **Animations:** GSAP (+ ScrollTrigger/React hooks)
- **UI:** Swiper.js, SCSS Modules (BEM)
- **Babel:** Настроил под поддержку React 19 и TS

## 📦 Установка и запуск

1. Установка зависимостей:
```bash
      npm install
```

2. Запуск в режиме разработки:
```bash
      npm run start
```

3. Сборка для продакшена (Desktop):
```bash
      npm run build:prod
```
